Chat Persistence Tests

2 Test Direct Chat Page Access
Go to chat page directly (not via request buttons)
Expected: All previous chat users should appear in left sidebar with:
  • User names and avatars
  • Item information
  • Last message preview
  • Message timestamps
3 Test Navigation Persistence
Navigate between pages and return to chat
Test Steps:
  1. Go to Chat page → verify users show
  2. Go to Home page
  3. Go to Browse Items page
  4. Return to Chat page → verify users still show
4 Test Chat History Loading
Click on users to verify chat history loads
Click on each user in the left sidebar and verify:
  • ✅ Previous messages appear in chat
  • ✅ Correct message order (oldest to newest)
  • ✅ Message timestamps are correct
  • ✅ Sender/receiver info is accurate
5 Test New Message Persistence
Send new messages and verify they persist
Test Process:
  1. Select a user and send a new message
  2. Navigate away from chat page
  3. Return to chat page
  4. Verify new message appears in chat history
  5. Verify last message shows in user preview
